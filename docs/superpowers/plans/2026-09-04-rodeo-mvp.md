# Rodeo MVP 垂直切片 实施计划

> **For agentic workers:** 本轮采用 Inline Execution（主会话内执行），因主要风险是
> 工具链/编译迭代，需要紧反馈循环。执行时用 checkbox（`- [ ]`）跟踪。

**Goal:** 交付一个可运行的端到端最小闭环：内置登录 → 创建/进入 Workspace → 创建 Entry（带 Task 标签）→ 表格视图展示。

**Architecture:** 三层分离（API → Service → Storage）。Leptos 0.7 全栈（SSR + 水合）+ Axum，
async-graphql 提供 GraphQL API，RocksDB 作为嵌入式文档存储，bincode 序列化文档。
认证走 HttpOnly cookie + JWT。

**Tech Stack:** Rust 1.97、Leptos 0.7、Axum 0.8、async-graphql 7、RocksDB、tokio、
serde/bincode、argon2、jsonwebtoken、ulid。

**Spec:** `spec/product_design.md` + `spec/technical_solution.md`（本计划从中推导）。

## 本轮范围（垂直切片）

包含：内置账号登录、Workspace 创建/列表、Entry 创建/列表、Task 标签打标、表格视图。
**本轮不实现**（后续阶段）：OAuth、Tantivy 全文检索、WebSocket 实时协作、附件文件存储、
审计日志、tiny-editor 富文本（先用 textarea 占位）、admin 管理端。

## 全局约束

- Rust 1.97，Leptos 0.7（SSR + hydrate），Axum 0.8，async-graphql 7，RocksDB。
- 文档用 bincode 序列化，索引值用 UTF-8 字符串键做前缀扫描。
- Entry `code` 为 16 字符（Ulid → base62 截断，冲突重试）。
- 密码 Argon2 哈希；会话 JWT 存 HttpOnly Secure SameSite cookie。
- 密码强度：最少 8 位，含大小写和数字。
- 权限：WorkspaceRole 排序 OWNER > MAINTAINER > WORKER > READER。
- 创建 Workspace 时自动生成 Task（Enum）与 Bug（Enum）两个内置标签。

## 任务分解

### Task 0: 工具链与验证
- [ ] 安装 cargo-leptos、wasm32 target，`cargo leptos --version` 通过。

### Task 1: 项目脚手架（最小可运行）
**Files:** `Cargo.toml`、`config.toml`、`src/main.rs`、`src/app.rs`、`src/config.rs`、`src/error.rs`、`style/tailwind.css`
**验证:** `cargo leptos dev` 编译通过并在 http://localhost:3000 输出一个静态页面（"Rodeo" 标题）。

### Task 2: 领域模型
**Files:** `src/domain/*.rs`
**接口产出:**
- `Account { id: Ulid, email: String, name: String, password_hash: String, is_admin: bool, created_at: DateTime<Utc> }`
- `Workspace { id: Ulid, name: String, slug: String, description: String, owner_id: Ulid, created_at: DateTime<Utc> }`
- `WorkspaceRole`（enum，派生 Ord）、`WorkspaceMember { workspace_id, account_id, role, joined_at }`
- `Entry { code: String, workspace_id: Ulid, title: String, detail: String, created_by: Ulid, updated_by: Ulid, created_at, updated_at }`
- `LabelValue`（enum: Null/Bool/Int/Float/String/Enum）、`LabelSchema { workspace_id, name, title, value_type, enum_values }`、`Labeling { entry_code, label_name, value, set_by, set_at }`
**验证:** `cargo test` 序列化往返 + `generate_entry_code()` 16 位字符集测试通过。

### Task 3: RocksDB 存储层
**Files:** `src/storage/rocksdb.rs`、`src/storage/mod.rs`
**接口产出:**
- `DocStore::open(path) -> Result<DocStore>`（打开/创建 CF）
- `put<T: Serialize>(cf, key: &[u8], value: &T)` / `get<T: DeserializeOwned>(cf, key) -> Result<Option<T>>`
- `put_kv(cf, key, value_bytes)`（索引用）/ `scan_prefix(cf, prefix) -> Vec<(Vec<u8>, Vec<u8>)>`
- CF 常量：accounts、accounts_email_idx、workspaces、workspaces_slug_idx、workspace_members、entries、entries_by_workspace、label_schemas、labelings
**验证:** `cargo test` 用 tempdir 做 put/get + 前缀扫描测试。

### Task 4: 认证服务
**Files:** `src/service/auth.rs`、`src/service/mod.rs`
**接口产出:**
- `AuthService::register(email, name, password) -> Result<Account>`（校验密码强度 + Argon2）
- `AuthService::login(email, password) -> Result<(Account, String /*jwt*/)>`
- `AuthService::verify_token(token) -> Result<AuthContext { account_id: Ulid }>`
- `AuthService::bootstrap_admin()`（首次启动建管理员）
**验证:** `cargo test` 注册 + 登录成功/密码错误/强度校验失败。

### Task 5: Workspace / Entry 服务
**Files:** `src/service/workspace.rs`、`src/service/entry.rs`
**接口产出:**
- `WorkspaceService::create(actor, name, slug, desc) -> Result<Workspace>`（创建 + 自动加 Owner + 内置 Task/Bug 标签）
- `WorkspaceService::list_for(account_id) -> Result<Vec<(Workspace, WorkspaceRole)>>`
- `WorkspaceService::get_by_slug(slug) -> Result<Workspace>`
- `EntryService::create(actor, workspace_id, title) -> Result<Entry>`（生成 code）
- `EntryService::list(workspace_id) -> Result<Vec<Entry>>`
- `EntryService::set_labeling(actor, entry_code, label_name, value) -> Result<Labeling>`
**验证:** `cargo test` 创建 Workspace 后内置标签存在、创建 Entry 生成唯一 code、打标 upsert。

### Task 6: GraphQL API 层
**Files:** `src/api/graphql.rs`、`src/api/mod.rs`
**接口产出:**
- `GraphqlContext { auth: Option<AuthContext>, services: Arc<Services> }`
- Query: `me`、`workspaces`、`workspace(slug)`、`entries(workspaceId)`、`labelSchemas(workspaceId)`
- Mutation: `login`、`logout`、`register`、`createWorkspace`、`createEntry`、`setLabeling`
- `graphql_handler`（async-graphql-axum GraphQL endpoint，从 cookie 注入 auth）
**验证:** 用 curl 对 `/api/graphql` 发 query/mutation 冒烟。

### Task 7: 前端页面与端到端联调
**Files:** `src/frontend/graphql_client.rs`、`src/frontend/pages.rs`、`src/frontend/mod.rs`、修改 `src/app.rs`
**页面:** `/login`、`/workspaces`、`/:workspace_slug`（表格 + 新建 Entry + Task 下拉打标）
**验证:** 浏览器走通 登录 → 建 workspace → 建 entry → 打 Task=Open → 表格可见。

## 关键实现要点（对齐 spec）

- Entry code：`fn generate_entry_code() -> String`：Ulid 转 bytes → base62 → 截断 16 字符，冲突重试（配合存储层唯一索引）。
- 乐观并发：MVP 阶段先跳过 expectedUpdatedAt 冲突检测，后续阶段补。
- 权限：GraphQL resolver 内用 `ctx.require_role(ws_id, min_role)` 校验成员角色。
- 首次启动：`main.rs` 检测 accounts CF 为空则 `bootstrap_admin()`（读取 config 或默认 admin@local / 随机密码打印到 stdout）。
