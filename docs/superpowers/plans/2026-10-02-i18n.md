# i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Rodeo's frontend UI fully translated into 6 languages (zh, en, ja, pt, es, ar) with an AppBar language switcher that defaults to the browser locale (English fallback).

**Architecture:** In-tree i18n (no new crate) following the existing `provide_theme`/`use_theme` shape. A `Locale` enum + `I18nController` carries the active language in a `RwSignal`; `i18n!()` macro looks up keys in locale JSON files embedded at compile time. SSR resolves locale from `?lang=` → `rodeo_lang` cookie → `Accept-Language` → English, writes `<html lang>`/`<html dir>` so SSR and hydrate align. A `<head>` inline script reads `localStorage.rodeo_lang` to avoid flash on returning visits. Arabic is RTL; CSS does minimal overrides under `[dir="rtl"]`.

**Tech Stack:** Rust 2021, Leptos 0.8, leptos_meta, leptos_router, serde_json, gloo-storage (existing), web-sys (existing). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-02-i18n-design.md`

## Global Constraints

- No new Rust unit tests (per `~/.claude/projects/.../memory/no-backend-unit-tests.md`). Verification gate per task: `make check` (native + wasm type check) and where UI: `make build`.
- After every change: `make check` must pass before commit. After UI changes: `make build` must also pass.
- Project layout per CLAUDE.md is preserved; no workspace splits.
- Translation strings are stored in `locales/{en,zh,ja,pt,es,ar}.json`. Keys are flat dot-namespaced strings, English sentence case (e.g., `appbar.new_entry`, `login.submit`). `en.json` and `zh.json` are the source of truth and must always be 1:1 in keys.
- The `i18n!()` macro lives in `src/frontend/i18n_macros.rs`. Macro syntax: `i18n!("namespace.key")` or `i18n!("namespace.key", name = expr, ..)`. It returns a `Fn() -> String` closure so it stays reactive.
- 200 OK on SSR/hydrate alignment: when localStorage has `rodeo_lang`, the head inline script sets `<html lang/dir>` BEFORE `<HashedStylesheet>`, matching what the server would have produced. The server also reads the cookie path so a cookie set on a previous visit wins over Accept-Language.
- Arabic (`ar`) is RTL; `<html dir="rtl">` is set on the server and by the inline script. CSS handles layout flip via `[dir="rtl"]` selectors — no pixel value rewrites.
- Service-side text (GraphQL error messages, AI summaries, user data) is NOT in scope. Only frontend UI strings.

## Review Focus

Inputs / failure modes the spec implies but no single task exercises; each line below is pinned to the task whose test (the verification step) covers it.

1. **Accept-Language `q=` quality factors** (e.g., `fr-FR;q=0.9,zh;q=0.8`) — Task 3 must rank and pick the highest-q match that maps to one of the six supported locales.
2. **Locale alias normalization** (e.g., `zh-CN`, `zh-Hans-CN`, `zh-Hant`) — Task 2's `Locale::from_browser` must reduce these to `Locale::Zh`.
3. **Hydrate mismatch when localStorage differs from SSR locale** — Task 3's inline-script must apply localStorage's value before `<HashedStylesheet>` mounts, and Task 4's button must not flicker.
4. **Missing key fallback chain** (locale → en → key string) — Task 1's `t()` must never return empty / panic on a missing key; Task 14's `check-locales.mjs` catches structural drift at build time, but the runtime fallback is what users see.
5. **Arabic `[dir="rtl"]` layout regressions** — Task 15's CSS overrides must keep `.wside`, `.agent-panel`, timeline, login form visually sane when flipped.
6. **Cookie `rodeo_lang` overrides Accept-Language** — Task 3's resolver reads cookie first; verification step in Task 3 curls with `Cookie: rodeo_lang=ja` and checks `<html lang="ja">`.

- [ ] **Step 2: Write `src/frontend/i18n.rs`**

The module is gated so server-side imports stay minimal. Use `include_str!` to embed both locale files as `&'static str`. Build the lookup `HashMap<&'static str, &'static str>` lazily via `OnceLock`. The `t()` function looks up the active locale; on miss, falls back to the en map; on miss, returns the key string itself and warns once via `tracing` if the `tracing` crate is available server-side (otherwise no-op log).

The key parser: split `"appbar.new_entry"` into `("appbar", "new_entry")`, look up in nested map; flat dotted keys via the helper below.

```rust
use leptos::prelude::*;
use serde::Deserialize;
use std::collections::HashMap;
use std::sync::OnceLock;

#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub enum Locale {
    Zh,
    En,
    Ja,
    Pt,
    Es,
    Ar,
}

impl Locale {
    pub fn as_str(self) -> &'static str {
        match self {
            Locale::Zh => "zh",
            Locale::En => "en",
            Locale::Ja => "ja",
            Locale::Pt => "pt",
            Locale::Es => "es",
            Locale::Ar => "ar",
        }
    }
    /// Short label rendered inside the AppBar language button.
    pub fn short_label(self) -> &'static str {
        match self {
            Locale::Zh => "中",
            Locale::En => "EN",
            Locale::Ja => "日",
            Locale::Pt => "PT",
            Locale::Es => "ES",
            Locale::Ar => "ع",
        }
    }
    /// Long label rendered in the language dropdown.
    pub fn label(self) -> &'static str {
        match self {
            Locale::Zh => "中文",
            Locale::En => "English",
            Locale::Ja => "日本語",
            Locale::Pt => "Português",
            Locale::Es => "Español",
            Locale::Ar => "العربية",
        }
    }
    pub fn is_rtl(self) -> bool { matches!(self, Locale::Ar) }

    pub const ALL: [Locale; 6] = [Locale::Zh, Locale::En, Locale::Ja, Locale::Pt, Locale::Es, Locale::Ar];

    pub fn from_str_ci(s: &str) -> Option<Self> {
        match s.to_ascii_lowercase().as_str() {
            "zh" | "zh-cn" | "zh-tw" | "zh-hans" | "zh-hant" => Some(Locale::Zh),
            "en" | "en-us" | "en-gb" => Some(Locale::En),
            "ja" => Some(Locale::Ja),
            "pt" | "pt-br" | "pt-pt" => Some(Locale::Pt),
            "es" | "es-es" | "es-mx" => Some(Locale::Es),
            "ar" => Some(Locale::Ar),
            _ => None,
        }
    }

    /// Reduce any browser-language string ("zh-CN", "zh-Hans-CN", "fr-FR") to a base
    /// language ("zh","zh","fr"), then try `from_str_ci`.
    pub fn from_browser(s: &str) -> Option<Self> {
        let s = s.trim();
        if s.is_empty() { return None; }
        if let Some(loc) = Self::from_str_ci(s) { return Some(loc); }
        // Strip region / script suffixes.
        let base = s.split(['-', '_']).next().unwrap_or(s);
        Self::from_str_ci(base)
    }
}

#[derive(Deserialize)]
struct LocaleJson {
    #[serde(default)]
    #[allow(dead_code)]
    _meta: HashMap<String, String>,
    #[serde(flatten)]
    sections: HashMap<String, HashMap<String, String>>,
}

/// Flat lookup map: "appbar.new_entry" -> "新建 Entry".
type FlatMap = HashMap<String, String>;

fn build_flat(json: &str) -> FlatMap {
    let parsed: LocaleJson = serde_json::from_str(json)
        .unwrap_or_else(|e| panic!("locale JSON malformed: {e}"));
    let mut out = FlatMap::with_capacity(64);
    for (section, kvs) in parsed.sections {
        for (k, v) in kvs {
            out.insert(format!("{section}.{k}"), v);
        }
    }
    out
}

fn map_for(loc: Locale) -> &'static FlatMap {
    static EN: OnceLock<FlatMap> = OnceLock::new();
    static ZH: OnceLock<FlatMap> = OnceLock::new();
    static JA: OnceLock<FlatMap> = OnceLock::new();
    static PT: OnceLock<FlatMap> = OnceLock::new();
    static ES: OnceLock<FlatMap> = OnceLock::new();
    static AR: OnceLock<FlatMap> = OnceLock::new();
    match loc {
        Locale::En => EN.get_or_init(|| build_flat(include_str!("../../locales/en.json"))),
        Locale::Zh => ZH.get_or_init(|| build_flat(include_str!("../../locales/zh.json"))),
        Locale::Ja => JA.get_or_init(|| build_flat(include_str!("../../locales/ja.json"))),
        Locale::Pt => PT.get_or_init(|| build_flat(include_str!("../../locales/pt.json"))),
        Locale::Es => ES.get_or_init(|| build_flat(include_str!("../../locales/es.json"))),
        Locale::Ar => AR.get_or_init(|| build_flat(include_str!("../../locales/ar.json"))),
    }
}

#[derive(Clone, Copy)]
pub struct I18nController { pub locale: RwSignal<Locale> }

impl I18nController {
    /// Look up an id in the current locale, fall back to en, fall back to the id itself.
    pub fn t(&self, id: &str) -> String {
        let loc = self.locale.get_untracked();
        if let Some(v) = map_for(loc).get(id) { return v.clone(); }
        if let Some(v) = map_for(Locale::En).get(id) { return v.clone(); }
        id.to_string()
    }

    /// Look up with `{name}`-style interpolation. Args is a slice of (placeholder, value).
    pub fn tf(&self, id: &str, args: &[(&str, &str)]) -> String {
        let mut s = self.t(id);
        for (k, v) in args {
            let pat = format!("{{{k}}}");
            s = s.replace(&pat, v);
        }
        s
    }

    pub fn set(&self, loc: Locale) {
        self.locale.set(loc);
    }
}

pub fn provide_i18n(initial: Locale) -> I18nController {
    let ctrl = I18nController { locale: RwSignal::new(initial) };
    provide_context(ctrl);
    ctrl
}

pub fn use_i18n() -> I18nController {
    use_context::<I18nController>().expect("I18nController 未提供")
}
```

///   view! { <button>{i18n!("login.submit")}</button> }

        }
    }};
}

- [ ] **Step 1: Add `from_accept_language` to `Locale` (in `src/frontend/i18n.rs`)**

Append to the `impl Locale` block:

```rust
/// Parse an `Accept-Language` header value (e.g. `fr-FR;q=0.9,zh-CN;q=0.8,en;q=0.5`)
/// and return the highest-q entry that maps to one of our six locales.
/// Entries with no `q=` default to 1.0. Items with `q=0` are skipped.
pub fn from_accept_language(header: &str) -> Option<Self> {
    let mut best: Option<(f32, Self)> = None;
    for raw in header.split(',') {
        let item = raw.trim();
        if item.is_empty() { continue; }
        let (tag, q) = match item.split_once(";q=") {
            Some((t, q)) => (t.trim(), q.parse::<f32>().unwrap_or(1.0)),
            None => match item.split_once(';') {
                Some((t, _)) => (t.trim(), 1.0),
                None => (item, 1.0),
            },
        };
        if !(q > 0.0) { continue; }
        if let Some(loc) = Self::from_browser(tag) {
            match best {
                Some((bq, _)) if bq >= q => {}
                _ => best = Some((q, loc)),
            }
        }
    }
    best.map(|(_, l)| l)
}
```

- [ ] **Step 2: Add a `resolve_initial_locale` helper in `src/app.rs`**

Above the `App` component:

```rust
use crate::frontend::Locale;
use http::HeaderMap;

fn resolve_initial_locale(query_lang: Option<&str>, headers: &HeaderMap) -> Locale {
    // 1. ?lang= override (debug)
    if let Some(q) = query_lang {
        if let Some(loc) = Locale::from_browser(q) { return loc; }
    }
    // 2. cookie rodeo_lang
    if let Some(cookie) = headers.get(http::header::COOKIE).and_then(|v| v.to_str().ok()) {
        for pair in cookie.split(';') {
            let mut kv = pair.trim().splitn(2, '=');
            if let (Some(k), Some(v)) = (kv.next(), kv.next()) {
                if k.trim() == "rodeo_lang" {
                    if let Some(loc) = Locale::from_browser(v.trim()) { return loc; }
                }
            }
        }
    }
    // 3. Accept-Language
    if let Some(al) = headers.get(http::header::ACCEPT_LANGUAGE).and_then(|v| v.to_str().ok()) {
        if let Some(loc) = Locale::from_accept_language(al) { return loc; }
    }
    // 4. fallback
    Locale::En
}
```

- [ ] **Step 2: Create `scripts/check-locales.mjs`**

A Node.js script (matches the existing `scripts/agent-e2e.mjs` style) that reads all six files and asserts every locale has the same key set as en:

```javascript
#!/usr/bin/env node
import { readFileSync } from "node:fs";
import { fileURLToPath } from "node:url";
import { dirname, resolve } from "node:path";

const __dirname = dirname(fileURLToPath(import.meta.url));
const localesDir = resolve(__dirname, "../locales");

function flatKeys(obj, prefix = "") {
  const out = [];
  for (const [k, v] of Object.entries(obj)) {
    if (k === "_meta") continue;
    const path = prefix ? `${prefix}.${k}` : k;
    if (v && typeof v === "object" && !Array.isArray(v)) {
      out.push(...flatKeys(v, path));
    } else {
      out.push(path);
    }
  }
  return out.sort();
}

const ref = JSON.parse(readFileSync(resolve(localesDir, "en.json"), "utf8"));
const refKeys = flatKeys(ref);
const refSet = new Set(refKeys);

let failed = false;
for (const name of ["zh", "ja", "pt", "es", "ar"]) {
  const data = JSON.parse(readFileSync(resolve(localesDir, `${name}.json`), "utf8"));
  const keys = flatKeys(data);
  const set = new Set(keys);
  const extra = keys.filter((k) => !refSet.has(k));
  const missing = refKeys.filter((k) => !set.has(k));
  if (extra.length || missing.length) {
    failed = true;
    console.error(`[${name}] missing: ${missing.length}, extra: ${extra.length}`);
    if (missing.length) console.error("  missing:", missing.join("\n           "));
    if (extra.length) console.error("  extra:  ", extra.join("\n           "));
  }
}
process.exit(failed ? 1 : 0);
```
